# codes-fonciers-cen
Liste des codes sql, permettant la gestion et la visualisation des données foncières du CEN Pays de la Loire 

### codes_serveur_distant 
Requête sql permettant de mettre à disposition les données foncières du CEN Pays de la Loire, pour la fédération des CEN de France, par le biais de tables distantes.

### codes_bilan_foncier
Requêtes sql permettant de récupérer les données foncières permettant de dresser le bilan de fin d'année du CEN Pays de la Loire.
